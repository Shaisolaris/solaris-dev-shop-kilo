# Solaris Dev Shop for Kilo

61 specialist employees plus one chief-of-staff coordinator: 62 workflows. This native profile preserves the pinned Solaris 0.65.0 runtime and adds zero employee capabilities.

Install the complete package through the host plugin manager. Host tools, approvals and runtime requirements apply; Python helpers need Python 3.10 or later. This package grants no permissions, adds no MCP server, changes no model/provider configuration, and starts no background schedule. The native adapter registers the bundled workflows on demand.
